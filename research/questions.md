# Research questions for Purple Team control-validation experiments

## RQ1
How reliably can endpoint configuration drift be detected across controlled Windows failure/adversarial **fixture** scenarios?

## RQ2
How much does telemetry correlation reduce false positives compared with static configuration checks?

## RQ3
Does independent post-remediation verification significantly reduce false recovery claims versus command-success checks?

## RQ4
What is the tradeoff between detection sensitivity and false-positive rate on authorized vs unauthorized configuration changes?

## RQ5
Which telemetry event types contribute most to detection performance in the purple fixture suite?

## Non-goals
These questions do **not** ask how to build malware, stealth tooling, or real-world offensive capability.
