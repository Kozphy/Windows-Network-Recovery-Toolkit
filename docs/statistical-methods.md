# Statistical Methods — Research Benchmark

This document describes uncertainty estimation for benchmark dataset v1. All numbers in
`benchmarks/statistical_summary.csv` are generated by `experiments/stats.py` — not hand-edited.

## Estimator

| Field | Value |
|-------|-------|
| Method | Percentile bootstrap |
| Confidence level | 95% (alpha = 0.05) |
| Resamples | 1000 |
| Random seed | 42 (deterministic) |

## Metrics with intervals

- **accuracy** — exact primary-class match rate
- **macro_f1** — unweighted mean of per-class F1 (preferred under class imbalance)
- **abstention_rate** — fraction predicting `INSUFFICIENT_DATA` / `ERROR_INSUFFICIENT_DATA`

## Assumptions

1. Cases are treated as IID for resampling (portfolio-sized benchmark; clusters not modeled).
2. Bootstrap resampling is with replacement at the case level.
3. Intervals describe uncertainty **on this fixture set**, not enterprise population inference.

## Interpretation

- A wide interval (e.g. accuracy CI spanning 0.0–0.27 on n=22) indicates small-sample uncertainty.
- Overlapping CIs between baselines do **not** automatically imply "no difference" — we avoid p-hacking.
- Paired tests were not applied: baselines share cases but change prediction logic; macro F1 bootstrap is reported per baseline independently.

## Limitations

- n=22 cases → high variance; held-out split (5 cases) is for reporting separation only.
- Synthetic fixtures may not represent live endpoint telemetry distributions.
- Policy/safety metrics are not bootstrapped in v1 (bounded rates reported point-only).
