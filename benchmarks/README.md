# Generated benchmark evidence

This directory contains reviewable artifacts generated by the executable workflow in
[`../experiments/README.md`](../experiments/README.md). It is not a hand-maintained scorecard.

## Artifact lineage

```text
tests/fixtures/research/v1/*.json
        + experiments/manifest.json
        + experiments/configs/*.json
                         |
                         v
             run_benchmark.py / run_ablations.py
                         |
                         v
             experiments/results/*.jsonl
                         |
                         v
                  compute_metrics.py
                         |
                         v
   results.csv / confusion_matrix.csv / ablations.csv / metrics.json
                         |
                         v
                     build_report.py
                         |
                         v
                 benchmark_report.md
```

Every aggregate number is derived from raw executable-run rows. The run manifests record source
commit, tracked-worktree status, dataset digest, configuration digest, Python/platform metadata,
case count, and replay mismatch count.

## Artifacts

- `results.csv` — per-split and overall B0-B3 classification/governance metrics.
- `confusion_matrix.csv` — long-form expected/predicted counts.
- `ablations.csv` — per-split and overall B3 component-ablation metrics and deltas.
- `metrics.json` — machine-readable copy of all aggregate rows.
- `environment.json` — benchmark and ablation run manifests.
- `benchmark_report.md` — generated summary with limitations and reproduction commands.

The authoritative case-level evidence remains under `../experiments/results/`.

## Review checklist

A reviewer should verify:

1. `dataset.sha256` matches `experiments/manifest.json`.
2. `tracked_worktree_dirty` is `false` for a published run.
3. `replay_mismatch_count` is zero or explicitly investigated.
4. Development, held-out, adversarial, and aggregate rows are not conflated.
5. Failures remain visible in the confusion matrix and raw predictions.
6. No fixture-only number is described as production or population performance.

## Interpretation boundary

The v1 dataset is small, synthetic, and repository-authored. Its `held_out` split is a workflow
control, not an independently collected validation set. Results can demonstrate reproducibility,
adapter behavior, and known failure modes; they cannot establish external validity, statistical
significance, MTTR reduction, or production safety.

## Regeneration

```powershell
python experiments/scripts/run_benchmark.py --config experiments/configs/benchmark-v1.json
python experiments/scripts/run_ablations.py --config experiments/configs/ablations-v1.json
python experiments/scripts/compute_metrics.py
python experiments/scripts/build_report.py
```

Do not edit generated metric values manually. Change code, configuration, or a newly versioned
dataset, then regenerate the complete artifact chain.
